# Pacific Coast Highway for FHCM

> **Community beta · provided as is.** PCH is in active development. Expect bugs and changes between releases. Back up your personal save and use Sandbox with Standard racers for a first Drive.

PCH covers Highway 1 and Old Coast Road in Big Sur. The current release candidate is Review 72 Beta 1 with the full-roster California plate update. One map package exposes the launcher’s Off, Light, Medium, and Heavy traffic profiles and the Standard and Experimental Tour Drivatar profiles.

[PCH downloads](https://github.com/fhcustommaps/pch-public-preview/releases) · [Install with or without the launcher](docs/INSTALL.md) · [Known beta issues](docs/KNOWN-ISSUES.md)

A compatible owned FH2 installation and Azimuth are required. See the [release checksum manifest](docs/FHCM-PCH-Review72-beta1-california.parts.json) for the tested California Plates package.
